Paradaisy

Programming  ·  Prototype Secondhand Clothing Website
HTML / CSS PHP MySQL SQL E-Commerce Circular Fashion

Paradaisy is a student-initiated circular fashion prototype — a secondhand clothing platform where gently used garments are collected, sorted, photographed, and resold at fair prices. Proceeds are donated to charitable organisations with full transparency through published donation records.

Built for the Programming module, this project pushed beyond HTML/CSS into server-side development: PHP handles product listing logic, user sessions, and checkout flows, while MySQL manages the product catalogue, orders, and donation data. The frontend implements a complete e-commerce UX — product pages, shopping cart, and purchase confirmation — all hand-coded from scratch.

All product photographs were used with explicit permission from the store owner. The website is ONLY for student project and will NOT use for any business purpose. The platform also serves as a small-scale data activism exercise, publishing transparent records of where donated proceeds go.

02

Duolingo Impact

D&AD New Blood Awards 2026  ·  Team Project Role: Web Developer
HTML5 CSS JavaScript Interactive Design D&AD Brief

An interactive website built in response to the D&AD New Blood Awards 2026 brief for Duolingo, an assignment for the working in digital media team module. The goal: shift the platform's public perception from "unhinged meme owl" to educational pioneer with genuine global impact — targeting the 16–24 age group.

The site serves as the campaign's digital backbone, weaving together the team's three outputs: the interactive website, an Instagram UX flow video, and a physical pop-up installation in Leeds. Interactive design elements address AI anxiety, foreground human communication skills, and connect each daily learning streak to Duolingo's 125 million learners worldwide.

Entirely hand-coded in VS Code — no templates, no website builders — giving full technical and brand control. As the team's web developer, the focus was on translating the campaign strategy into a seamless interactive experience without relying on frameworks.

03

Fire Simulation Website

Digital Media & The Senses  ·  Immersive Web
HTML / CSS JavaScript Web Audio API Immersive Experience Critical Design Data Feminism Interactive Sensory

A critical, immersive web response to the Tai Po Wang Fuk Yuen fire — built to restore what news coverage omits: breath, noise, confusion, and the quiet acts of care that emerge in disaster.

The site unfolds across six sequential sections. A drag-and-drop fire interaction triggers alarm audio and transforms a "before" image to "after." A volume slider asks "How much are you willing to hear?" — but keeps the breath and rumble audible even at minimum, because some realities persist. In the darkest section, mouse movement speed controls heartbeat intensity: fast movement = urgency; slow movement = collapse or dying signal.

A mandatory 10-second pause in Section 5 applies the principle of slow computing — deliberately interrupting the scroll-past speed of online disaster content. Section 6 invites users to choose a role (bystander, escapee, recorder, silenced) and surfaces missing data: questions that public reporting rarely answers.

Grounded in D'Ignazio & Klein's Data Feminism — the argument that what gets counted counts, and what is never recorded shapes whose realities are rendered visible.

04

InTouch Foundation

UI/UX Redesign  ·  Foundation Project
HTML CSS UI/UX Charity Sector Accessibility

A redesign of the InTouch Foundation — a UK charity supporting underprivileged families through education and healthcare. The original site's primary goals (online donations, volunteer recruitment, event promotion) were buried under an unclear information hierarchy and inconsistent visual language.

This project marks the beginning of my journey from graphic design into coding and interface design: the point where visual thinking needed to become something a browser could actually render. The redesign prioritised a cleaner donation flow, clearer calls-to-action, and a more accessible colour and typography system — translating charity-sector design principles into functional HTML and CSS.

It is a deliberately humble starting point — but one that shaped how I now approach the relationship between design decisions and their technical implementation.
